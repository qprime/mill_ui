# Recipe 21: Simple Shaker Door

**Status:** Draft
**Difficulty:** Beginner
**Demonstrates:** Basic domain inset, profile cut, flat pocket

## Overview

This recipe builds a classic shaker door using a single outer domain and an inset
panel domain. The outer boundary is profiled through, and the panel receives a
6mm pocket.

## Output

Running the example writes these files to `output/`:
- `ast.json`
- `intents.json`
- `preview.svg`

## Run

```bash
PYTHONPATH=. python docs/recipes/21_simple_shaker_door/example.py
```
