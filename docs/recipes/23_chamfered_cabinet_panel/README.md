# Recipe 23: Chamfered Cabinet Panel

**Status:** Draft
**Difficulty:** Beginner
**Demonstrates:** Chamfer feature, full-surface pocket, profile cut

## Overview

This recipe creates a 300x400mm panel with a 6mm pocket across the surface
and a 5mm by 3mm chamfer on the outer edge.

## Output

Running the example writes these files to `output/`:
- `ast.json`
- `intents.json`
- `preview.svg`

## Run

```bash
PYTHONPATH=. python docs/recipes/23_chamfered_cabinet_panel/example.py
```
