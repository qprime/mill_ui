# Recipe 24: Shelf Dados Side Panel

**Status:** Draft
**Difficulty:** Beginner
**Demonstrates:** Programmatic groove placement with flat pockets

## Overview

This recipe creates a 600x800mm cabinet side with five evenly spaced shelf
dados. Each dado is 19mm wide and 10mm deep, spaced at 150mm intervals.

## Output

Running the example writes these files to `output/`:
- `ast.json`
- `intents.json`
- `preview.svg`

## Run

```bash
PYTHONPATH=. python docs/recipes/24_shelf_dados_side/example.py
```
