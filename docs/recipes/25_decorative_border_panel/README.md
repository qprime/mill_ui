# Recipe 25: Decorative Border Panel

**Status:** Draft
**Difficulty:** Intermediate
**Demonstrates:** Nested insets, subtract, thin pocket grooves

## Overview

This recipe creates a 350x450mm panel with three concentric rectangular
border grooves. Each groove is 3mm wide and 2mm deep, inset at 15mm,
30mm, and 45mm from the outer edge.

## Output

Running the example writes these files to `output/`:
- `ast.json`
- `intents.json`
- `preview.svg`

## Run

```bash
PYTHONPATH=. python docs/recipes/25_decorative_border_panel/example.py
```
