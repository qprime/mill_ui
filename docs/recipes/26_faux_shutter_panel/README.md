# Recipe 26: Faux Shutter Panel

**Status:** Draft
**Difficulty:** Intermediate
**Demonstrates:** split_horizontal spacing, repeated chamfered grooves

## Overview

This recipe builds a shutter-style panel with 12 horizontal louver grooves.
The grooves are evenly spaced by splitting the domain into 13 slats and
using the gaps between them. Each groove is pocketed to 8mm and then
chamfered for an angled look.

## Output

Running the example writes these files to `output/`:
- `ast.json`
- `intents.json`
- `preview.svg`

## Run

```bash
PYTHONPATH=. python docs/recipes/26_faux_shutter_panel/example.py
```
