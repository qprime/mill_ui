# Recipe 29: Picture Frame Panel

**Status:** Draft
**Difficulty:** Intermediate
**Demonstrates:** Subtract, inner profile cut, rabbet pocket, chamfer edge

## Overview

This recipe creates a 300x400mm frame with a 200x300mm inner opening.
It adds a 10mm wide, 5mm deep rabbet around the opening and an optional
outer chamfer.

## Output

Running the example writes these files to `output/`:
- `ast.json`
- `intents.json`
- `preview.svg`

## Run

```bash
PYTHONPATH=. python docs/recipes/29_picture_frame_panel/example.py
```
