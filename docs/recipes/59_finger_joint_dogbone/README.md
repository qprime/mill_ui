# Recipe 59: Finger Joint with Automatic Dogbone

Demonstrates automatic dogbone fillets on finger joints. CNC routers leave radiused internal corners at each finger notch; dogbone bores provide clearance so the mating fingers mesh flush.

**Key concepts:**
- Finger joint with default dogbone — no explicit `dogbone` field needed
- Box assembly with 4 panels, finger-jointed at sides
- Each notch automatically gets 2 dogbone bores at its internal corners
