# Recipe 60: Half-Lap with Automatic Dogbone

Demonstrates automatic dogbone fillets on half-lap joints. Both panels in a half-lap receive a slot with 2 internal corners that need dogbone clearance.

**Key concepts:**
- Half-lap joints with default dogbone — no explicit `dogbone` field needed
- Cubby assembly with horizontal shelves and vertical partitions
- Each half-lap notch on both panels automatically gets dogbone bores
